Постановление Правительства РФ от 23.12.2024 № 1875 · ПРЕДЕЛЬНЫЕ ЗНАЧЕНИЯ доли стоимости используемых для производства одной единицы отдельных медицинских изделий иностранных материалов (сырья) в цене конечной продукции

Постановление Правительства РФ № 1875 Предельные значения преамбула

Действует
ред. от 01.10.2026 · сверено 11.10.2026
Наименование медицинского изделияПредельное значение доли стоимости используемых для производства одной единицы отдельных медицинских изделий иностранных материалов (сырья) в цене конечной продукции, процентовПодтверждающий документ
1.Устройства для переливания крови, кровезаменителей и инфузионных растворовне более 20сертификат по форме СТ-1 и документ, подтверждающий, что доля стоимости использованных материалов (сырья) иностранного происхождения в цене конечной продукции составляет не более 20% для каждого наименования медицинского изделия
2.Контейнеры для заготовки, хранения и транспортирования донорской крови и ее компонентовне более 10сертификат по форме СТ-1 и документ, подтверждающий, что доля стоимости использованных материалов (сырья) иностранного происхождения в цене конечной продукции составляет не более 10% для каждого наименования медицинского изделия
3.Расходные материалы для аппаратов искусственной вентиляции легкихне более 10сертификат по форме СТ-1 и документ, подтверждающий, что доля стоимости использованных материалов (сырья) иностранного происхождения в цене конечной продукции составляет не более 10% для каждого наименования медицинского изделия
4.Расходные материалы для аппаратов донорского плазмафереза/ тромбоцитаферезане более 40сертификат по форме СТ-1 и документ, подтверждающий, что доля стоимости использованных материалов (сырья) иностранного происхождения в цене конечной продукции составляет не более 40% для каждого наименования медицинского изделия
5.Расходные материалы для аппаратов искусственного (экстракорпорального) кровообращенияне более 40сертификат по форме СТ-1 и документ, подтверждающий, что доля стоимости использованных материалов (сырья) иностранного происхождения в цене конечной продукции составляет не более 40% для каждого наименования медицинского изделия
6.Мочеприемники и калоприемникине более 20сертификат по форме СТ-1 и документ, подтверждающий, что доля стоимости использованных материалов (сырья) иностранного происхождения в цене конечной продукции составляет не более 20% для каждого наименования медицинского изделия
